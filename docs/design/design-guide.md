# Ordo 디자인 가이드 v3 — 최종 (Pretendard)

> **이 문서와 `docs/design/mockup-v3/`가 최종 기준입니다.** v1·v2 시안(docs/mockups, mockup-html, mockup-v2)은 쓰지 않습니다.
> 시안 원본: `mockup-v3/app.html`(어시스턴트), 공통 `mockup-v3/v3.css`

## 1. 방향

- **에디토리얼 그리드 + 업무 도구의 읽기 쉬움.** 잡지 페이지처럼 여백과 정렬로 정리하되, 20~60대 누구나 바로 읽고 누를 수 있게
- **박스 대신 가는 선과 여백**으로 구분. 카드 안에 카드, 칩, 둥근 모서리, 그림자 없음
- **장식 없는 평범한 말.** 영문 대문자 라벨, 슬래시 라벨, 대괄호 버튼, 슬로건형 문구 쓰지 않음

## 2. 글꼴

- **Pretendard** 하나만 사용 (한글·영문·숫자 전부, 랜딩과 동일). 다른 글꼴 섞지 않음
- 숫자는 `font-variant-numeric: tabular-nums` (티켓번호·시각·점수 정렬용, 고정폭 글꼴 대신)

| 용도 | 크기 / 굵기 |
|---|---|
| 랜딩 큰 제목 | 44px / 700 |
| 문서 제목 (요청서) | 34px / 700 |
| 섹션 제목 | 26px(랜딩) · 15px(앱) / 600~700 |
| 본문 | **15~16px** / 400, 줄간격 1.65~1.75 |
| 보조·메타 | 13px / 400, 회색 |

> 본문을 15px 밑으로 내리지 않습니다 (연령대 고려).

## 3. 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `ink` | `#111111` | 제목, 주요 글자, 주요 버튼 |
| `body` | `#2B2B2B` | 긴 본문 |
| `mute` | `#6F6F6F` | 라벨, 메타 정보 |
| `faint` | `#A6A6A6` | 번호, 힌트, 플레이스홀더 |
| `line` | `#E3E3E3` | 모든 구분선 |
| `bg` | `#FFFFFF` | 배경 |
| `soft` | `#F6F6F4` | 사용자 메시지, 스크린샷 받침 |
| `risk` | `#C8341F` | **위험도 표시에만** (등급 글자, 점수) |

상태는 **색 배지 없이 글자로**: "요청서 초안 · 접수 전", "보완 대기", "처리 중", "완료". 꼭 필요하면 글자색만 `risk`.

## 4. 레이아웃

**그리드:** 12칸, 칸 간격 24px, 좌우 여백 64px(랜딩) / 40px(앱)

**어시스턴트 화면 (`/app`)** — 대화 + 요청서 나란히
- 상단 바 64px: 로고, 텍스트 메뉴(어시스턴트 · 내 요청 · 백오피스), 오른쪽 사용자명 · 소속 · 로그아웃
- 왼쪽 대화 500px: 사용자 메시지는 `soft` 배경 블록, AI는 배경 없이 "Ordo" 이름 + 본문. 하단 입력창 + "보내기"
- 오른쪽 요청서 문서: 메타 한 줄(상태 · 요청번호) → 큰 제목 → 2단 항목표(선으로 구분) → 섹션(왼쪽 180px 섹션명 / 오른쪽 내용): 위험도(번호 행), 확인이 필요한 내용(밑줄 입력), 자동 보정 기록 → 하단 안내 + 취소(텍스트) · 접수하기(검정)
- 요청서가 없을 땐 오른쪽에 "요청을 말씀하시면 이곳에 요청서가 작성됩니다" 한 줄만
- 운영 담당자: 같은 구조, 오른쪽에 조회 결과(요청 목록을 선 행으로)
- 백오피스: 왼쪽 목록(선 행: 번호 · 제목 · 상태 · 위험도 · 마감) / 오른쪽 선택한 요청의 문서형 상세

**랜딩 (`/`)**
1. 헤더 72px: 로고 / 소개 · 사용 방법 · 보안 · **로그인**
2. 히어로: 왼쪽 7칸 ORDO 워드마크, 오른쪽 4칸 하단 정렬 소개 2줄 + 메타 + 시작하기 버튼
3. 실제 앱 화면 캡처 (얇은 테두리 받침 + 아래 캡션)
4. 사용 방법: 왼쪽 3칸 섹션 제목 / 오른쪽 8칸 번호 행 4개
5. 보안: 왼쪽 큰 문장 / 오른쪽 하단 정렬 설명
6. 푸터 메타 한 줄

## 5. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 주 버튼 | 높이 44px, 검정 배경 흰 글자 15px 600, 직각 |
| 보조 버튼 | 글자 + 밑줄 (취소, 사용 방법 보기) |
| 행 목록 | 위쪽 가는 선, 번호(faint) · 이름 · 설명(mute) · 값 오른쪽 정렬 |
| 입력 | 밑줄 하나 (박스 아님) |
| 알림 | 화면 우측 상단 흰 바탕 + 검정 1px 선, 제목·남은 시간·"확인" 링크. 위험 이벤트만 왼쪽 4px `risk` 막대 |

## 6. 문구

- 평범하고 구체적으로: "요청서를 작성했습니다", "롤백 절차를 적어주세요", "접수하기 전에는 백오피스에 등록되지 않습니다"
- 슬로건·은유 금지 ("질서를, 한 계단씩" 같은 문장 쓰지 않음)
- 영문은 고유명사(Ordo)와 요청번호에만

## 7. 모션

- 랜딩만: 스크롤 시 요소가 아래에서 20px 올라오며 나타남 (0.9s, 순차 0.1s), 스무스 스크롤(lenis)
- 앱: 새 메시지·요청서 갱신 시 짧은 페이드(0.25s)만. 그 외 없음
- `prefers-reduced-motion`이면 끔

## 8. Tailwind

```js
theme:{extend:{
  colors:{ink:'#111111',body:'#2B2B2B',mute:'#6F6F6F',faint:'#A6A6A6',line:'#E3E3E3',soft:'#F6F6F4',risk:'#C8341F'},
  fontFamily:{sans:['Pretendard','sans-serif']},
  borderRadius:{none:'0',DEFAULT:'0'},
}}
```
글꼴: `pretendard` 패키지 (랜딩에서 이미 설치)
